01 / DocFoo

Document questions with citations and figures.

Index papers, books and documents into a knowledge graph. Ask across a collection and get source citations and relevant figures. Open a cited passage in the reader, inspect recorded retrieval, or check where the evidence stops.

  • Cross-document knowledge-graph retrieval
  • Source citations & original figures
  • Recorded retrieval replay
02 / Study workspace

Read, annotate and ask questions.

Highlight a passage and ask DocFoo about it without leaving the reader. Save your own notes and images beside the text. Teammates can use the same indexed evidence in their work.

  • Passage-linked questions & replies
  • Personal notes with images
  • Shared document evidence
03 / Marimo

Interactive Python notebooks.

Build local reactive notebooks with controls, plots and Python cells. Change a parameter to update the results. With your approval, a teammate can inspect variables, edit cells and run checks in the same live Python kernel.

  • Reactive controls & plots
  • Live notebook pairing
  • Python export
04 / Teammates

Persistent AI teammates.

Give each teammate its own model, thinking level, instructions, saved memory and workspace. Ask Chief to delegate research, checks or document creation. The teammates work in their own conversations and report back to Chief.

  • Independent conversations & models
  • Chief delegation & reports
  • Reusable skills & scheduled routines
05 / Connected apps

1,500+ apps through Composio.

Connect external apps, then select the accounts and individual tools each teammate can use. Give one teammate read access and another a different set of tools. Review write actions separately.

  • App catalogue & account connections
  • Per-teammate tool selection
  • Read/write permissions
06 / Browser editing

Edit local HTML with comments.

Select an element in the preview, write what you want changed, and send the comments to a teammate. The teammate edits the source file; you review the updated page in the same preview.

  • Element-linked comments
  • Local HTML source edits
  • Before/after preview

07 / Permissions

Tool permissions and approvals.

Set the tools each teammate can use. Review file writes, code execution and notebook access. Teammates can ask clarification questions in the conversation before they act.

  • Per-teammate tool access
  • Action-specific approvals
  • Clarifying questions
08 / Telegram

Telegram

Telegram conversation sync.

Continue the same desktop conversation in Telegram. Switch teammates with /bot, send files and receive generated documents as attachments.

  • Existing conversation & context
  • Teammate switching
  • File attachments

Pair your own Telegram bot. PiKins must stay running on a PC that’s online and awake.

Getting started.

Install PiKins, connect a provider, and assign a task.

  1. 01

    Install PiKins.

    Use the Windows installer, or extract the portable ZIP and run PiKins.exe.

  2. 02

    Connect a provider.

    Add your supported model-provider connection in Settings. Choose models and thinking levels for your teammates.

  3. 03

    Assign a task.

    Ask Chief to delegate work, or talk to a teammate directly. Select a workspace and grant the tools the task needs.

DocFoo, Marimo and external app connections are optional.
