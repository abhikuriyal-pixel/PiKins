# Local typefaces

The public landing page uses **Lato 400 and 700**, matching the academic webpage reference. The Latin WOFF2 subsets include the page's punctuation and are served locally; no Google Fonts requests occur at runtime.

Sources (Google Fonts, Lato v25):

- `Lato-Regular.woff2`: https://fonts.gstatic.com/s/lato/v25/S6uyw4BMUTPHjx4wXg.woff2
- `Lato-Bold.woff2`: https://fonts.gstatic.com/s/lato/v25/S6u9w4BMUTPHh6UVSwiPGQ.woff2
- License: `Lato-OFL.txt`, from https://github.com/google/fonts/blob/main/ofl/lato/OFL.txt

Lato is by Łukasz Dziedzic and distributed under the SIL Open Font License 1.1.

The unused `InterVariable.woff2` and its `OFL.txt` are retained from the previous design. They are not requested by the public page.
